Как сайт реагирует на ввод пользователя

  • HTML — это дом (стены, окна, двери)
  • CSS — это дизайн интерьера (обои, мебель, цвета)
  • JavaScript — это то, что происходит в доме при нажатии на выключатель света

HTML

язык разметки, который создаёт структуру веб-страницы


<h1>Привет!</h1>
<p>Это текст</p>
  • Это заголовок
  • Это абзац текста
  • Это картинка
  • Это кнопка

CSS

язык стилей, который делает сайт красивым


h1 {
  color: blue;
  font-size: 40px;
}
  • Заголовок — синий, большой, жирный
  • Текст — серый, 16px
  • Кнопка — зелёная с тенью

Как работает CSS?

CSS работает по принципу выбери элемент → примени стиль

Выбираем все заголовки h1


h1 {
  ...
}

Описываем как выглядят все заголовки h1


h1 {
  color: red;
  font-size: 32px;
}

С чем мы с вами будем работать

CSS переменные

коробочка с названием, внутри которой хранится значение


:root {
  --main-color: #1a237e;
}
Переменная main-color содержит в себе цвет

Можно использовать вместо значения


h1 {
    color: var(--main-color);
}

Как работают цвета в CSS


color: white; /* мало вариантов */
color: #FFFFFF; /* HEX-код */
  • Первые 2 символа = RED (красный)
  • Средние 2 символа = GREEN (зелёный)
  • Последние 2 символа = BLUE (синий)
